# 知识库回流功能改造需求（补充知识库）

> 依据：V4.6.1【APP云店】优化分类下搜索商品逻辑 用例补充知识库的多轮人审反馈（2026-08-06/07）沉淀。
> 适用对象：`skills/knowledge-base/`（KB 入库回流管道：xmind_source 适配器 / changeset / apply_transaction / completeness_gate / markdown_model）。
> 权威门禁文案：同目录 [`SKILL.md`](./SKILL.md)（v0.2.0）；本文件为改造需求真源，Skill 须与之对齐。

---

## 一、知识抽取（用例 XMind → 知识候选）

| # | 要求 | 说明 |
|---|------|------|
| 1.1 | **仅抽取 P0/P1 用例** | P2/P3 用例不得作为知识点入库 |
| 1.2 | **禁止非功能用例** | 性能、集成、兼容性、稳定性（重复测试）、并发、网络异常等一律排除；「非功能」模块分支（性能测试/集成测试）整支跳过 |
| 1.3 | **规则一句话提炼** | 取清洗后的用例标题（去掉 `[P0]`、`APP-`/`云店-`/`场景X：`前缀），**禁止**拼接「操作+预期」细节；知识库面向人工快速查阅，务求简约 |
| 1.4 | **页面名识别** | 从步骤/期望/标题识别「xx页/xx页面」：动词锚定（进入/打开/跳转到/在…页）优先，句尾匹配次之；过滤噪声（翻页/页签/分页/加载更多、观察/查看等动词前缀、或/和/与连词、超长片段） |

## 二、模块与页面归置

| # | 要求 | 说明 |
|---|------|------|
| 2.1 | **页面角色：主页面 vs 子页面** | 主页面 = 二级模块入口页（如 销售/销售 → 销售列表页；云店/选购 → 选购页）；用例涉及的**子功能页**（销售开单商品选择页、云店搜索结果页）一律归为**子页面** |
| 2.2 | **云店用例归置** | 标题以「云店-」开头的用例 → 模块 **云店/选购**；页面统一 **云店搜索结果页**（子页面） |

## 三、核心元素表（8 列 Schema）

| # | 要求 | 说明 |
|---|------|------|
| 3.1 | **表头固定 8 列** | `元素 \| 位置 \| 输入/选项 \| 展示内容 \| 交互 \| 交互结果 \| 后端接口 \| 下游影响说明` |
| 3.2 | **新增「展示内容」列** | 与「输入/选项」不同：针对**结果输出元素**，说明元素内展示什么（如 搜索结果 → 匹配的商品项列表）；输入类元素（搜索框）置「-」 |
| 3.3 | **容器/子元素关系** | 位置字段用「父容器 > 子元素」表达层级（`搜索结果 > 当前分类区块`、`分类筛选内选项`）；子元素必须紧跟所属主元素 |

## 四、字段填写规范

| # | 要求 | 说明 |
|---|------|------|
| 4.1 | **位置一句话** | 如 搜索框：页面顶部；分类标签：页面左侧 / 分类标签区；搜索结果：页面中部主区域；禁止留空 |
| 4.2 | **空字段用「-」** | 无法准确获得的字段一律用 `-`；**禁止**「待补充（历史）」等占位文案（含 renderBackendApiCell 无接口时的输出） |
| 4.3 | **接口只注接口** | 只说明涉及的接口（方法+路径），**不写入**参数/断言/请求体等细节 |

## 五、补充说明

| # | 要求 | 说明 |
|---|------|------|
| 5.1 | **仅 P0/P1 提炼** | 同 1.1 |
| 5.2 | **一句话** | 同 1.3 |
| 5.3 | **按元素分类** | 以 `### 元素名` 子标题分组；**多元素操作的规则，隶属「最终展示结果」的元素**（如搜索结果）；无归属的进「### 通用规则」 |
| 5.4 | **子标题顺序 = 核心元素顺序** | 与核心元素表的视觉顺序一致，**不得颠倒** |
| 5.5 | **无空行** | 子标题与列表项之间、子标题之间均不插入空行 |

## 六、元素排列（视觉顺序）

| # | 要求 | 说明 |
|---|------|------|
| 6.1 | **顶→底、左→右** | 核心元素行按页面布局顺序排列；子元素与所属主元素相邻 |
| 6.2 | 销售 · 销售开单商品选择页 | 搜索框 → 分类标签 → 商品分类 → 搜索结果 → 当前分类 → 全部类别 |
| 6.3 | 云店 · 云店搜索结果页 | 搜索框 → 搜索结果 → 分类筛选 → 当前分类 → 全部类别 → 云店商品标签 |

## 七、完整性门禁

| # | 要求 | 说明 |
|---|------|------|
| 7.1 | 元素必填项 | `name` / `interaction` / `result` 为阻塞缺口 |
| 7.2 | 建议项 | `backend_api` / `position` / `input_options` 等缺失仅告警，**不得阻塞**（业务规则元素可无接口/位置留「-」） |
| 7.3 | 业务 page 缺 URL | 业务规则通道登记的 `page` 缺 Web URL → **仅告警**；显式 `page_url` 变更缺 URL 仍阻塞 |
| 7.4 | 通道优先级 | 导航/技术引用仅 P0；业务规则仅 P0/P1；P2/P3 与非功能不得进入候选 |

## 八、验收标准（V4.6.1 样例基线）

- 销售/销售 · **销售开单商品选择页（子页面）**：核心元素 6 个（顺序见 6.2）+ 按元素分组的补充说明（### 分类标签/搜索结果/当前分类/全部类别/通用规则）
- 云店/选购 · **云店搜索结果页（子页面）**：核心元素 6 个（顺序见 6.3）+ 分组补充说明
- 0 阻塞缺口；空字段全部「-」；补充说明无空行、子标题顺序正确；页面关系.md 与元素文件 `页面角色` 一致
