## 二、跨模块关联映射

### 2.1 高频跨模块链路

| 链路名称 | 模块调用顺序 | 典型场景 | 测试要点 |
|---------|------------|---------|---------|
| 销售完整链路 | 商品 → 销售 → 库存 → 资金 → 分析 | 销售开单完整流程 | 商品选择、库存扣减、资金收款、销售统计 |
| 进货完整链路 | 商品 → 进货 → 库存 → 资金 → 分析 | 进货开单完整流程 | 商品选择、库存入库、资金付款、进货统计 |
| 退货完整链路 | 销售/进货 → 库存 → 资金 | 销售退货/进货退货 | 库存回库、资金退回 |
| 云店订单链路 | 云店 → 销售 → 库存 → 资金 | 云店订单处理 | 订单同步、库存扣减、资金收款 |

### 2.2 模块依赖矩阵

| 模块 | 依赖模块 | 依赖原因 |
|------|---------|---------|
| 销售 | 商品、客户、库存、资金 | 销售需要商品、客户信息，需要扣减库存、生成收款 |
| 进货 | 商品、供应商、库存、资金 | 进货需要商品、供应商信息，需要增加库存、生成付款 |
| 库存 | 商品、仓库 | 库存关联商品和仓库 |
| 资金 | 销售、进货 | 资金流水来源于销售收款、进货付款 |
| 分析 | 销售、进货、库存、资金 | 分析数据来源于各业务模块 |

## 三、自动匹配规则

### 3.1 关键词匹配优先级

**优先级1：精准匹配** — 需求标题或内容明确出现模块名称 → 直接映射  

**优先级2：功能关键词匹配** — 出现功能关键词 → 按第一节归属  

**优先级3：业务对象匹配** — 涉及业务对象 → 按对象所属模块映射  

**优先级4：影响范围推断** — 根据影响范围推断关联模块  

### 3.2 关键词匹配表（速查）

| 关键词组 | 映射模块 | 匹配优先级 |
|---------|---------|-----------|
| 商品、商品信息、商品档案、新增商品 | 商品-商品 | 1 |
| 规格、多规格、规格组合 | 商品-规格管理 | 1 |
| 单位、计量单位、单位换算 | 商品-单位管理 | 1 |
| 销售、销售单、销售开单、销售保存 | 销售-销售 | 1 |
| 退货、退货单、销售退货 | 销售-销售退货 | 1 |
| 进货、进货单、采购、进货开单 | 进货-进货 | 1 |
| 盘点、库存盘点 | 库存-盘点 | 1 |
| 调拨、跨仓调拨 | 库存-调拨 | 1 |
| 库存、库存查询、库存数量 | 库存-库存查询 | 1 |
| 收款、收款单、销售收款 | 资金-收款 | 1 |
| 付款、付款单、进货付款 | 资金-付款 | 1 |
| 云店、小程序、线上订单 | 云店（再细分二级） | 1 |
| 员工、员工管理、员工信息 | 设置-员工管理 | 1 |
| 权限、角色权限、权限配置 | 设置-角色权限 | 1 |
| 打印、打印模板、打印设置 | 设置-打印设置 | 1 |

### 3.3 多模块匹配规则

**规则1：主模块优先** — 多模块时主模块最高优先级  

**规则2：完整链路覆盖** — 完整业务链路时关联链路中模块  

**规则3：依赖模块自动关联** — 主模块确定后关联其依赖  

**规则4：人工确认机制** — 无法明确时输出待确认清单
