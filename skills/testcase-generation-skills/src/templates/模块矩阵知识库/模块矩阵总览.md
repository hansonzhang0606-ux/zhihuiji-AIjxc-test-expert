# 模块矩阵总览

> 仅一级 / 二级中文名；**不含**匹配规则、英文标识、关联对象。  
> 一行一个一级模块；二级用顿号「、」并列。目录 `{一级}/{二级}/` 须与本表一致。

| 销售 | 销售、云店订单、销售预订、销售退货、报价、业绩提成、快递服务、单据分享小程序 |
| 客户 | 客户、价格等级、报价管理 |
| 进货 | 供应商、进货、进货预订、进货退货 |
| 库存 | 盘点、调拨、组装、拆分、库存查询、库存预警、批次查询、保质期查询、序列号查询 |
| 资金 | 账户概览、转账、收款、付款、其他收入、其他支出、客户对账、供应商对账、资金流水 |
| 分析 | 销售统计、热销分析、员工业绩统计、进货统计、库存统计、经营利润 |
| 云店 | 我的云店、云店装修、云店商品排序、云店设置、选购、订单、我的 |
| 设置 | 商户信息、门店管理、仓库管理、员工管理、角色权限、POS设备、系统设置、用户偏好设置、打印设置、积分设置、系统初始化 |
| 三方应用 | 获客易、找企业、商品查询、鹰眼报告、智慧周转 |
| 非功能 | 性能测试、集成测试 |
