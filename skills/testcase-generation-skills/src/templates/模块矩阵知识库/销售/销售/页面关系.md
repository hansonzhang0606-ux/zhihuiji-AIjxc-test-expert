# 页面关系 · 销售 / 销售

## 1. 页面清单（跨端统一页面名称）

| 统一页面名称 | 角色 | 支持端 | 一句话说明 |
|--------------|------|--------|------------|
| 销售单列表页 | 主页面 | web+app | 查询与进入开单/查看的入口 |
| 销售单开单页 | 核心子页面 | web+app | 销售单编辑页：新增 / 修改 / 复制 共用同一开单页（入口动作不同） |
| 销售单详情页 | 核心子页面 | web+app | 销售单只读查看（Web 称「查看销售单页」；App 称「销售单详情页」） |
| 销售单开单成功页 | 子页面 | app | App 开单提交成功后的中间页，再进详情 |

### 1.1 跨模块目标页（本模块只记路径，不建本模块元素文件）

| 统一页面名称 | 所属模块（建议） | 一句话说明 |
|--------------|------------------|------------|
| 销售退货开单页 | 销售 / 销售退货 | 从本单详情「复制」进入的退货开单 |
| 进货开单页 | 进货 / 进货 | 从本单详情「复制」进入的进货开单 |

## 2. 电脑端（Web）

### 2.1 本端页面名（对照）

| 统一页面名称 | 本端页面名 |
|--------------|------------|
| 销售单列表页 | 销售单列表页 |
| 销售单开单页 | 新增销售单页 / 修改销售单页 / 复制销售单页（同一开单页，入口不同） |
| 销售单详情页 | 查看销售单页（销售单详情页） |

### 2.2 跳转路径

| 起点 | 动作 | 终点 |
|------|------|------|
| 销售单列表页 | 新增 | 销售单开单页 |
| 销售单列表页 | 修改 | 销售单开单页 |
| 销售单开单页 | 保存成功 | 销售单详情页 |
| 销售单详情页 | 修改 | 销售单开单页 |
| 销售单详情页 | 复制销售单 | 销售单开单页 |
| 销售单详情页 | 复制销售退货 | 销售退货开单页 |
| 销售单详情页 | 复制进货 | 进货开单页 |

> Web 另有更多从详情出发的复制/下游动作，未穷举；补知识时只追加本表行，不改统一页面名称规则。

### 3.1 本端页面名（对照）

| 起点 | 动作 | 终点 |

> App 页面整体少于 Web；未在上表出现的 Web 详情下游动作，默认 **App 未实现**，除非单独补路径。
