# 页面关系 · 销售 / 销售预订

## 1. 页面清单（跨端统一页面名称）

| 统一页面名称 | 角色 | 支持端 | 一句话说明 |
|--------------|------|--------|------------|
| 销售预定单列表页 | 主页面 | web+app | 查询与进入开单/查看的入口（产品亦称「销售订单」列表） |
| 销售预定单开单页 | 核心子页面 | web+app | 销售预定单编辑页：新增 / 修改 / 复制 共用同一开单页（入口动作不同） |
| 销售预定单详情页 | 核心子页面 | web+app | 销售预定单只读查看（Web 称「查看销售预定单页」；App 称「销售预定单详情页」） |
| 销售预定单开单成功页 | 子页面 | app | App 开单提交成功后的中间页，再进详情 |

## 2. 电脑端（Web）

### 2.1 本端页面名（对照）

| 统一页面名称 | 本端页面名 |
|--------------|------------|
| 销售预定单列表页 | 销售预定单列表页（产品称「销售订单」列表） |
| 销售预定单开单页 | 新增销售预定单页 / 修改销售预定单页 / 复制销售预定单页（同一开单页，入口不同） |
| 销售预定单详情页 | 查看销售预定单页（销售预定单详情页） |

### 2.2 跳转路径

| 起点 | 动作 | 终点 |
|------|------|------|
| 销售预定单列表页 | 新增 | 销售预定单开单页 |
| 销售预定单列表页 | 修改 | 销售预定单开单页 |
| 销售预定单开单页 | 保存成功 | 销售预定单详情页 |
| 销售预定单详情页 | 修改 | 销售预定单开单页 |
| 销售预定单详情页 | 复制销售预定单 | 销售预定单开单页 |

> 主路径按「销售」同构入库；其他下游动作未在原文给出，补知识时只追加本表行。
