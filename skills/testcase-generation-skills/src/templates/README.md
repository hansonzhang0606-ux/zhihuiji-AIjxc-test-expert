# templates — 经验文档与业务知识索引

本目录为用例生成与知识库相关的**只读**规则/知识落盘处。禁止复制进需求工作区 `output/{title}/`。

| 文档 / 目录 | 作用 | 主要消费者 | 类型 |
|-------------|------|------------|------|
| [`需求文档过滤规则.md`](./需求文档过滤规则.md) | 1A 前物理剔除「需求背景」等章节 | `filter_requirement_doc.js` / Stage1A | 硬规则 |
| [`隐式需求惯例.md`](./隐式需求惯例.md) | 进销存等隐含业务惯例（经验） | Stage1A LLM 按需 | 经验 |
| [`质量问题目录.md`](./质量问题目录.md) | 需求质检常见问题条目（经验） | Stage1A LLM 按需 | 经验 |
| [`模块匹配规则.md`](./模块匹配规则.md) | 需求文本 → 一/二级模块**如何匹配**（关键词等） | Stage3 `stage3_module.js` | 匹配规则 |
| [`标签规则.md`](./标签规则.md) | 产品 / 版本 / 端枚举与打标 | Stage1 1CTX | 硬规则 |

| [`用例平台导入配置.example.json`](./用例平台导入配置.example.json) | Stage5 DevOps 导入主数据/PRJ | `stage5/export_platform_p0_excel.js` | 配置样例 |
| [`模块矩阵知识库/`](./模块矩阵知识库/) | 模块分层、支持矩阵、页面关系、核心元素 | extract / 入库 / 3B | **业务知识真源** |

## 边界

- **模块分层 / 端支持**真源 = `模块矩阵知识库/模块矩阵总览.md`，不是 `模块匹配规则.md`。
- **匹配关键词**留在 `模块匹配规则.md`（及脚本内同步表），不进知识库业务树。
- 经验类文档宜逐步沉淀进 `模块矩阵知识库/` 对应模块页；本目录保留生成侧可读副本直至迁移完成。

## 默认 kb_root（样例）

未配置远程时：`src/templates/模块矩阵知识库/`。
