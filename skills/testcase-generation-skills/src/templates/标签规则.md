# 标签规则

> 对齐《星火项目背景》：本仓库 **Skills 仅支持星火产品线**（智慧记AI进销存 / ailit）。**智慧记**、**智慧记零售** 为其他产品线，识别到后应停止流程。

## 一、标签类型定义

### 1.1 标签分类体系（按判定顺序）

```
标签体系（判定顺序：产品 → 端 → 版本 → 角色）
├── ① 产品标签（Product Tags）          【必判，最先】
│   ├── 国内版 → 智慧记AI进销存（普通版）
│   └── 国际版 → ailit
├── ② 端标签（Platform Tags）
│   ├── PC端              # 星火 Web（含云店 B 端管理）
│   ├── APP端             # 星火 APP（含云店 B 端管理）
│   ├── 小程序端          # 云店 C 端（普通版）/ 单据分享小程序
│   └── H5端              # 云店 C 端（国际版 ailit）
├── ③ 版本标签（Version Tags）         【仅 PC端 / APP端】
│   ├── 开单版本          # 仅国内版；ailit 无开单
│   ├── 单店版本
│   └── 多店版本
└── ④ 角色标签（Role Tags）            【按需】
    ├── 老板角色
    └── 员工角色
```

> **已删除**：系统标签（并入产品标签）、业务场景标签、测试类型标签。

### 1.2 核心判定顺序（强制）

```
Step0（Confluence）向上查一层父页面命名 → 定产品线（星火 / 智慧记 / 智慧记零售）
        ↓
Step1 判定产品标签（国内版 / 国际版 ailit）
        ↓
Step2 判定端标签（PC / APP / 小程序 / H5）
        ↓
Step3 按端决定是否判定版本标签
        ├── 端含【PC端】或【APP端】 → 继续判定版本标签（开单/单店/多店）
        └── 端仅为【小程序端】和/或【H5端】 → 不判定、不使用版本标签
        ↓
Step4 按需判定角色标签
```

**硬规则：**
- **产品最先判**；星火 产品线只允许 `智慧记AI进销存` / `ailit`，禁止把标题里的「智慧记」单独打成产品
- 小程序端、H5端：**禁止**打版本标签
- 仅当端含 PC/APP 时，才匹配并落盘版本标签

### 1.3 Confluence 父级 → 产品线（Stage1 上下文）

拿到 Confluence 需求链接后，**向上查找一层**父页面 title：

| 父页面命名 | 产品线 | 产品范围 | Skills |
|------------|--------|----------|--------|
| **星火 V…** / **星火 v…** | 星火 | 智慧记AI进销存 + ailit | **继续** |
| **智慧记 V…** / **智慧记 v…**（非零售、非星火子项） | 智慧记 | 智慧记 | **停止**（不支持） |
| **智慧记零售版 V…** / **智慧记零售 V…** | 智慧记零售 | 智慧记零售 | **停止**（不支持） |

落盘：`session_info.source.parent_title` / `download_manifest.parent_title`；识别脚本优先读父级定产品线，再读标题【】收窄国内/国际。

**不支持产品线处理：** 人审①展示后，用户确认产品为智慧记/智慧记零售 → **禁止** `--approve`，**停止**后续 Stage1A/3/4。

### 1.4 星火应用场景 → 标签速查

| 应用场景 | 产品（先判） | 端 | 版本 | 说明 |
|----------|--------------|-----|------|------|
| **星火 Web/APP** | 国内版 + 国际版 | PC/APP | 国内：开单/单店/多店；国际：单店/多店 | 主场景；云店 B 端属其内 |
| **云店 C 端** | 与端联动 | 国内→小程序；国际→H5 | **不使用** | 扫 Web 码分流 |
| **单据分享小程序** | **仅国内版** | 小程序 | **不使用** | 禁止国际版/H5 |

## 二、产品标签规则（判定顺序 ①）

> 契约落盘全称：`智慧记AI进销存`、`ailit`。展示简称：**国内版**、**国际版**。
>
> **不测、不打标**：智慧记、智慧记零售（非星火 Skills 范围）。

### 2.1 产品标签定义

| 产品标签 | 契约全称 | 常见别名 | 说明 |
|----------|----------|----------|------|
| **国内版** | 智慧记AI进销存 | 普通版、国内版本、AI进销存 | 星火普通版 |
| **国际版** | ailit | 国际版本、Ailit、海外版 | 星火国际版 |

匹配时 **较长全称优先**（「智慧记AI进销存」不得拆成「智慧记」）。

### 2.2 产品标签匹配规则

**规则0：Confluence 父级（最高优先级）**
- 父级 **星火 V…** → 产品线=星火；允许产品仅 `智慧记AI进销存` / `ailit`；**剔除**标题/正文中单独命中的「智慧记」「智慧记零售」
- 父级 **智慧记 V…** → 产品线=智慧记；`products.in_scope=[智慧记]`；标记不支持，停止流程
- 父级 **智慧记零售版 V…** → 产品线=智慧记零售；`products.in_scope=[智慧记零售]`；停止流程
- 无父级信息 → 按标题/正文；仍禁止在星火 Skills 内默认选「智慧记」

**规则1：标题【】收窄（星火 产品线内，优先于正文）**
- 标题【】或标题行 **未** 出现国内/国际类产品关键词 → **默认国内版 + 国际版**（`智慧记AI进销存` + `ailit`）
- 标题 **仅** 写明【国内】/【普通版】/【国内版】等 → **仅**国内版
- 标题 **仅** 写明【国际】/【国际版】/【ailit】等 → **仅**国际版
- 标题 **同时** 写明国内与国际 → 两者都打

> 正文可补充收窄，但**标题未写国内/国际时，不因正文缺失而缩成单产品**；仅当标题或正文**明确**只涉及某一产品时，才落单产品。

**规则2：关键词（标题/正文）**
- "国内"、"普通版"、"中文" → 智慧记AI进销存
- "国际"、"ailit"、"多语言"、"海外" → ailit

**规则3：与端联动（产品已初步判定后）**
- 云店 C 端 + 小程序 → 国内版
- 云店 C 端 + H5 → 国际版
- 单据分享 → 仅国内版

**规则4：默认（星火）**
- 父级已确认为星火，且标题/正文均未明确国内或国际 → **国内版 + 国际版**
- 标题/正文明确国内+国际 → 两者都打
- 仅明确其一 → 只打该产品

### 2.3 产品标签示例

**示例1：** 父级「星火 V4.6」+ 标题「V4.6.2 【PC/APP】版本降级…」（**未写**国内/国际）→ **国内版 + 国际版**；**不是**单独「智慧记」

**示例2：** 父级「星火 V4.6」+ 标题「【国际版】【PC+移动】…」→ **仅**国际版（ailit）

**示例3：** 父级「星火 V4.6」+ 标题「【国内版】【PC】批量导入…」→ **仅**国内版

**示例4：** 父级「智慧记 V4.6」→ 产品=智慧记 → **停止**（Skills 不支持）

**示例5：** 单据分享小程序 → 仅国内版

## 三、端标签规则（判定顺序 ②）

### 3.1 端标签定义

| 标签 | 适用场景 | 约束 |
|------|----------|------|
| **PC端** | 星火 Web；云店 B 端管理 | **需**判版本 |
| **APP端** | 星火 APP；云店 B 端管理 | **需**判版本 |
| **小程序端** | 云店 C 端国内版；单据分享 | **不判版本** |
| **H5端** | 云店 C 端国际版 | **不判版本** |

### 3.2 端标签匹配规则

**规则1：标题【】收窄（优先于正文）**
- 标题【】**未**出现 PC/APP/小程序/H5/云店 等端关键词 → **默认 PC端 + APP端**
- 标题 **仅** 写明某一端（如【PC】、【APP/云店】、【小程序】）→ **仅**该端
- 标题 **同时** 写多端 → 按命中合并

> 正文不因未写端而收窄；**云店** 在标题中与 APP 并列时（如【APP/云店】）→ 视为 **APP端**（云店 B 端管理能力）。云店 C 端买家侧需标题明确【小程序】/【H5】。

**规则2：关键词**
- PC/Web/电脑/桌面 → PC端
- APP/手机/移动/云店 → APP端
- 小程序/微信 → 小程序端
- H5/手机网页 → H5端

**规则3：业务场景**
- 云店 B 端管理 → PC/APP（不因正文「云店」二字误打小程序/H5）
- 云店 C 端买家侧 → 按产品：国内→小程序，国际→H5
- 单据分享 → 小程序端

**规则4：默认**
- 标题未写端 → **PC端 + APP端**

### 3.3 端标签示例

**示例1：** 「PC端批量导入」→ 仅 PC端

**示例2：** 父级星火 + 「V4.6.0 【PC】批量上传商品图片」→ 仅 PC端

**示例3：** 父级星火 + 「6、自定义商品属性…」（**标题无【】端标识**）→ **PC端 + APP端**（默认）

**示例4：** 父级星火 + 「【APP/云店】优化分类下搜索」→ APP端

**示例5：** 「云店装修自定义首页」→ PC/APP（B 端，若标题无【】仍默认 PC/APP）

## 四、版本标签规则（判定顺序 ③，仅 PC / APP）

> 端不含 PC/APP → **跳过**，`version_tags` 为空。

### 4.1 版本标签定义

| 标签 | 约束 |
|------|------|
| **开单版本** | 仅国内版 PC/APP；ailit 禁止 |
| **单店版本** | 国内版与 ailit 均支持 |
| **多店版本** | 国内版与 ailit 均支持 |

### 4.2 版本标签匹配规则

**规则0：** 端不含 PC/APP → 不匹配版本

**规则1：标题【】收窄**
- 标题 **未** 写开单/单店/多店/连锁/门店 → **默认全选**（开单版 + 单店版 + 多店版）
- 标题 **仅** 写明某一版本 → 仅该版本
- 标题 **同时** 写多版本 → 按命中合并

> 展示层「全选」时不展示版本标签；落盘仍保留三版本供 3B 矩阵裁剪。

**规则2：** 模块（仅标题/正文明确时辅助）：库存→单店+多店；门店管理→多店

**规则3：** 产品×版本：ailit 禁止开单（3B 裁剪阶段处理）

**规则4：** 默认（PC/APP 且标题未写版本）→ **开单 + 单店 + 多店**

## 五、角色标签规则（判定顺序 ④）

按需判定；默认老板+员工（展示层全选时隐藏）。仅老板或仅员工生效时展示 `老板` / `员工`。

## 六、标签组合规则

### 6.1 组合优先级与生成顺序

1. **产品标签**（必出；Confluence 父级优先）
2. **端标签**
3. **版本标签**（仅 PC/APP）
4. **角色标签**（按需）

### 6.2 落盘 vs 展示（精简打标）

| 层级 | JSON 落盘 | XMind 展示 |
|------|-----------|------------|
| 产品 | `["智慧记AI进销存","ailit"]` | `国内版/国际版` |
| 端 | `["PC端","APP端"]` | `PC端/APP端` |
| 版本 | 开单/单店/多店 | **非全选才展示** `开单/单店/多店` |
| 角色 | 老板/员工 | **非全选才展示** |

展示顺序：**产品 → 端 →（版本）→（角色）**。实现：`scripts/lib/xmind_export.js` → `formatDisplayLabels`。

### 6.3 组合硬约束

| 约束 | 说明 |
|------|------|
| 星火 Skills | 产品仅智慧记AI进销存、ailit |
| 智慧记 / 智慧记零售 产品线 | 识别到即停止，不打星火 标签 |
| 小程序/H5 × 版本 | 禁止 |
| ailit × 开单 | 禁止 |
| 单据分享 | 仅国内版 + 小程序 |

## 七、标签自动匹配流程

```
Confluence 父级 title → 产品线（星火/智慧记/零售）
    ↓（不支持 → 停止）
① 产品标签
    ↓
② 端标签
    ↓
③ PC/APP？→ 是：版本标签 / 否：跳过版本
    ↓
④ 角色标签
    ↓
formatDisplayLabels 合并展示
```
