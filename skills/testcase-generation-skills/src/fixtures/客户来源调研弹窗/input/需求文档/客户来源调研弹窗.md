# 客户来源调研弹窗

> Fixture 假需求（FOUND-07），标题标识：【国际版】【PC+移动】

## 背景

新用户完成首笔销售单保存后，需要弹出「客户来源」调研弹窗，用于收集获客渠道。

## 功能说明

1. 仅对**从未产生过销售单**的账号，在首次保存成功后弹出调研弹窗。
2. 弹窗展示期间，原「保存成功」Toast 不显示。
3. 用户选择来源并确认后关闭弹窗；可跳过。
4. 需要上报弹窗曝光埋点一次。
5. 本次需求覆盖 **PC端、APP端**；小程序端不在范围内，但需确认无副作用。
6. 产品范围：**国际版**；国内版不在本次改动范围。

## 非目标

- 不改造支付/收账流程。
- 不修改库存扣减逻辑。
